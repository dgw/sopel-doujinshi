# sopel-doujinshi

Sopel plugin to fetch info about doujins linked on IRC

## Installing

Releases are hosted on PyPI, so after installing Sopel, all you need is `pip`:

```shell
$ pip install sopel-doujinshi
```

## Configuring

The easiest way to configure `sopel-doujinshi` is via Sopel's
configuration wizard—simply run `sopel-plugins configure doujinshi`
and enter the values for which it prompts you.
